# CodeAlpha Hangman Game

A simple text-based Hangman game built with Python as part of the CodeAlpha Python Programming Internship.

## 🎯 Project Overview

The player tries to guess a randomly selected word one letter at a time.

The game allows a maximum of **6 incorrect guesses**. The player wins by correctly guessing all the letters before reaching the maximum number of incorrect attempts.

## ✨ Features

* Randomly selects a word from a predefined list
* Letter-by-letter guessing
* Maximum of 6 incorrect guesses
* Displays the player's current progress
* Detects repeated guesses
* Shows the letters already guessed
* Win and loss conditions
* Simple console-based interface

## 🛠️ Concepts Used

* Python
* Lists
* Strings
* `random`
* `while` loops
* `if-elif-else`
* User input
* Basic validation

## ▶️ How to Run

Make sure Python is installed on your computer.

Clone the repository:

```bash
git clone https://github.com/Bilospher/CodeAlpha_Hangman.git
```

Open the project folder:

```bash
cd CodeAlpha_Hangman
```

Run the game:

```bash
python Hangman.py
```

## 🎮 How to Play

1. Start the program.
2. The game randomly selects a word.
3. Enter one letter at a time.
4. Correct guesses reveal the letter.
5. Incorrect guesses reduce your remaining attempts.
6. Guess the complete word before reaching 6 incorrect guesses to win.
